# Pull Request Template

The canonical governed pull request template is:

```text
.github/PULL_REQUEST_TEMPLATE.md
```

GitHub auto-applies pull request templates only from supported repository locations such as `.github/PULL_REQUEST_TEMPLATE.md` or `.github/PULL_REQUEST_TEMPLATE/*.md`.

This file remains as a discoverable pointer for teams copying templates into another repository. Do not maintain a second copy here; update `.github/PULL_REQUEST_TEMPLATE.md` instead.
